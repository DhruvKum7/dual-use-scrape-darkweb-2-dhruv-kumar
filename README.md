## ⚡ Features

✨ What this project does:

- 📄 Parse HTML using BeautifulSoup  
- 🔍 Filter pages containing:
  - `NV`
  - `702`
- 📬 Extract:
  - Emails  
  - Usernames  
  - Phone numbers  
- 🧹 Remove duplicates  
- 📦 Export JSONL format  
- 🧪 Automated testing
